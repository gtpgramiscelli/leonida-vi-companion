# Leonida Companion — Guia Nativo Android de GTA VI

Aplicativo nativo Android (Kotlin + Jetpack Compose + Material 3) feito para acompanhar sua jogatina de **100% em Grand Theft Auto VI**, 100% offline e com **atualização automática via GitHub Releases**.

## Funcionalidades
- **Checklist Oficial do 100% ("A Long Road")**: todos os 35 requisitos oficiais + contadores rápidos de campo (WAiNK, Binóculos, Stick Ups e Estande de Tiro).
- **Mapa Interativo de Leonida**: mapa vetorial com zoom/pan das 6 regiões e 15 lugares secretos/easter eggs marcáveis.
- **Cheats de GTA VI (PS5 / Xbox Series)**: guia completo do novo sistema de D-Pad pelo celular, busca, favoritos e requisitos de desbloqueio.
- **Resumo dos Capítulos com Escudo Anti-Spoiler**: capítulos futuros ficam bloqueados e o capítulo atual exibe apenas a premissa segura.
- **Fun Facts, Dicas e Dossiê de Leonida**: curiosidades verificadas, dicas práticas e guia de elenco/regiões.
- **Auto-Update via GitHub Releases**: verifica automaticamente novas versões neste repositório e instala por cima mantendo seu progresso salvo.

## Baixar a versão mais recente
Baixe o `.apk` na aba **[Releases](https://github.com/gtpgramiscelli/leonida-vi-companion/releases/latest)** e instale no Android 8.0+.
